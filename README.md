# udevapp-img

유데브앱 블로그 이미지 호스팅 (GitHub Pages).

- 발행처 = https://sun5022.github.io/udevapp-img/
- 쓰는 곳 = Blogger `UDevApp Blog` 본문 이미지 (Blogger API 에 이미지 업로드 기능이 없어 외부 주소 참조)
- 정본 원본 = `00_Workspace` 레포 `03_Work/15_패키징/05_홍보/02_초안/*/` (여기 것은 웹용 축소본)

## 규칙

- 가로 최대 1400px · WebP q85 · 장당 100KB 내외
- 파일명 = 영문 소문자 + 하이픈, **주소가 글에 박히므로 한번 올린 이름은 바꾸지 않는다**
- 내용을 고칠 때는 **같은 이름으로 덮어쓴다** → 발행된 글이 자동으로 새 이미지를 받는다

## 주소 형식

```
https://sun5022.github.io/udevapp-img/blog/<이름>.webp
```
